Privacy policy

Card Tracker is a personal tool used only by its owner. This policy describes how it handles Google user data.

What it accesses

With the owner's consent, Card Tracker uses the Gmail read-only permission (gmail.readonly) to read the owner's own bank alert emails. It cannot send, change or delete email.

How the data is used

Amounts, dates and merchant names from those alerts are used only to show the owner their own card spending totals.

Where the data is stored

All data, including the access token, stays on the owner's own computer. It is not uploaded to any server run by Card Tracker.

Sharing

Google user data is not sold, shared with or transferred to anyone, and is not used for advertising or to train AI models.

Removing access

Access can be withdrawn at any time from Google Account → Security → Third-party connections. Deleting the app's local data folder removes everything it stored.
